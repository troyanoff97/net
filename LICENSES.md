# Происхождение материалов

- `hero-sad.webp`, `hero-layer.webp` и портрет в `og-preview.jpg` получены из PNG, предоставленного заказчиком. Права на фотографию определяются условиями исходника.
- `sad-theme.mp3` — оригинальная минорная композиция с синтезированными тембрами фортепиано, виолончели и струнных. `rain.mp3` и файлы `sfx/` синтезированы для сайта. Сторонние записи, сэмплы и саундтреки не использованы. Авторские аудиофайлы предоставляются для использования, изменения и распространения по CC0 1.0. [Текст CC0 1.0](https://creativecommons.org/publicdomain/zero/1.0/)
- Зерно, текстура дождя, трещины, favicon и компоновка превью созданы для проекта. Интерфейс использует системные шрифты.
