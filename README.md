# Нет. — Искусство разочаровывать

Интерактивный статический сайт для универсального отказа. Для запуска нужен Python 3 или любой другой статический HTTP-сервер.

```sh
python3 -m http.server 8000
```

Запустите команду из этой папки и откройте [http://localhost:8000/](http://localhost:8000/). Все изображения, аудио и эффекты находятся в проекте. Сборка и сетевые зависимости не требуются.

## Режимы просмотра

- «Нет.» видно сразу. «Принять неизбежное» запускает 42-секундный монтаж с возможностью перейти к финалу. Escape пропускает монтаж или закрывает финал.
- «Смотреть вручную» переводит к прологу. Все семь частей также доступны обычной прокруткой.
- После первого жеста браузер может разрешить воспроизведение. Кнопка «Звук» и ползунок управляют всей звуковой сценой. При скрытии вкладки звук и монтаж приостанавливаются.
- Значок ссылки и «Поделиться разочарованием» открывают генератор. Параметр `q` добавляет вопрос в пролог. Например, `/?q=Ты%20согласен%3F`. Вопрос передаётся в URL, поэтому он виден получателю ссылки.

## Размещение

[Публичная версия на GitHub Pages](https://troyanoff97.github.io/net/).

Разместите содержимое этой папки на статическом хостинге с HTTPS. Для превью в мессенджерах укажите в `og:image` абсолютный HTTPS-адрес файла `assets/og-preview.jpg`. Локальная ссылка подходит для проверки. При размещении генератор использует адрес открытого сайта.
